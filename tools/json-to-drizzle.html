Guide

About JSON to Drizzle ORM Generation

Column type mapping

string → text(), integer → integer(), float → real() (SQLite) / doublePrecision() (PG), boolean → boolean(), ISO date → timestamp(), null → column marked .default(null).

Dialect differences

PostgreSQL uses pgTable and supports native boolean() and timestamp(). MySQL uses mysqlTable with tinyint() for booleans. SQLite uses sqliteTable with integer() for booleans and text() for dates.

Primary keys

If "Auto primary key" is enabled, the generator detects id fields and marks them with .primaryKey(). If none exist, a synthetic id: integer('id').primaryKey().notNull() is prepended.

Import statement

The output includes the correct import line for the selected dialect, e.g. import { pgTable, text, integer } from 'drizzle-orm/pg-core' so you can paste directly into your project.
