About JSON to Zod Schema Generation

Zod type mapping

string → z.string(), integer/float → z.number(), boolean → z.boolean(), null → z.null() or .nullable(), array → z.array(), object → nested z.object().

What is .strict() mode?

By default Zod ignores unknown keys in objects. With .strict() enabled, Zod throws a validation error if the input contains any keys not defined in the schema. Enable this for strict API contract enforcement.

Inferred TypeScript types

When "Export inferred type" is enabled, the output includes export type MyType = z.infer<typeof mySchema>. This gives you a TypeScript type that is always in sync with the Zod schema — no duplication needed.

Arrays of mixed types

If a JSON array contains mixed types (e.g., [1, "hello", true]), the generator produces z.array(z.union([z.number(), z.string(), z.boolean()])). Empty arrays produce z.array(z.unknown()).
