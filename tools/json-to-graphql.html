About JSON to GraphQL Type Generation

Scalar type mapping

string → String, integer → Int, float → Float, boolean → Boolean, null → nullable (no !). Fields named id or _id → ID scalar.

Non-null modifier

When "Non-null (!)" is enabled, all non-null JSON values get the ! modifier, indicating required fields in your schema. Turn it off to make all fields nullable — useful for partial update inputs.

Nested objects

Nested JSON objects generate separate type and input blocks, referenced as field types in the parent. e.g., address: Address! with a separate type Address { ... } block.

Query boilerplate

When enabled, the generator outputs a sample type Query with get and list fields, plus a type Mutation with create and update operations using the generated input type.
