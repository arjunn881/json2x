About JSON to Prisma Schema Generation

How are types mapped?

JSON primitives map to Prisma scalars: string → String, integer → Int, float → Float, boolean → Boolean, null → String?, ISO date string → DateTime.

What about nested objects?

Nested JSON objects generate separate model blocks. The parent model gets a relation field (e.g., address Address?) and the child model gets a back-relation with @relation.

Are arrays supported?

Arrays of objects generate a related model with a one-to-many relation (posts Post[]). Arrays of primitives are mapped to Json type since Prisma doesn't natively support scalar arrays in all databases.

What is the @id annotation?

When "Auto @id field" is enabled, the generator detects fields named id, _id, or uuid and marks them with @id. If none is found, a synthetic id Int @id @default(autoincrement()) is added.
