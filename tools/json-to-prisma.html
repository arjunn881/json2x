Frequently Asked Questions

Frequently Asked Questions about JSON to Prisma Schema Generator

How do I generate a Prisma schema model from JSON data?

Paste your sample JSON object. The tool infers Prisma scalar types and generates ready-to-use model blocks for your schema.prisma file.

How are JSON primitive types mapped to Prisma scalar types?

string → String, integer → Int, float → Float, boolean → Boolean, null → String?, and ISO date strings → DateTime.

How are nested objects converted into relational Prisma models?

Nested objects generate separate child model blocks, and the parent model receives relation fields with foreign key references.

How does the auto @id primary key detection work?

When enabled, the generator detects fields named id, _id, or uuid and tags them with @id. If none exists, an auto-incrementing id Int @id @default(autoincrement()) is added.

Which databases can I use with the generated schema?

Prisma models are database-agnostic and work with PostgreSQL, MySQL, SQLite, SQL Server, CockroachDB, and MongoDB.

Can I include a datasource and client generator block?

Yes. Toggle the Datasource Header switch to include generator client and datasource db blocks at the top of the output.

How are arrays of objects mapped to one-to-many Prisma relations?

Arrays of objects (e.g. "posts": [ {...} ]) generate a child model with a one-to-many relation (posts Post[]).

How do I apply the generated schema to my Prisma project?

Paste the model blocks into your schema.prisma file and run npx prisma db push or npx prisma migrate dev.
