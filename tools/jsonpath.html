Frequently Asked Questions about JSONPath Tester & Query Evaluator

What is JSONPath and how do I query JSON documents?

JSONPath is a query expression language for JSON, similar to XPath for XML. It allows you to select and extract specific nodes or values using expressions like $.store.book[*].author.

What is the difference between $ and @ operators in JSONPath?

$ denotes the root object or array of the JSON document. @ represents the current node being evaluated within a filter expression predicate (e.g. [?(@.price < 20)]).

How do I filter array items by property conditions?

Use filter expressions: $.users[?(@.age >= 18 && @.active == true)] returns all user objects meeting both conditions.

How do I use recursive descent (..) to find all occurrences of a key?

The double dot operator ($..propertyName) recursively searches all levels of the document and returns an array of all matching values.

How does array slicing work in JSONPath?

Array slicing uses [start:end:step] syntax: $.items[0:5] returns the first 5 elements, and $.items[-1:] returns the last element.

Can I use the wildcard operator (*) to select all properties or array items?

Yes. $.store.* selects all child elements of store, and $.books[*].title extracts the title from every book in the array.

What JSONPath implementation is used in this browser tester?

Our evaluator follows standard JSONPath specifications supported by Jayway, jsonpath-plus, and Kubernetes jsonpath output templates.

Can I test JSONPath queries on large API response payloads?

Yes. Queries are evaluated in real time in browser memory, allowing rapid iteration on complex API payloads.
