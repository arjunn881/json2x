About JSON to Code Conversion


        

          

            
How are field names converted?

            
Go uses PascalCase field names with `json:"..."` struct tags. Rust uses snake_case with `#[serde(rename)]` annotations. Python preserves original field names.

          

          

            
Is parsing 100% private?

            
Yes. Data never leaves your machine. All code generation takes place locally inside your web browser.
