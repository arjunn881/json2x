About the JSON Multi-Format Converter

When do I use TypeScript vs Zod?

Use interface / type for compile-time type safety inside a TypeScript project. Add a Zod schema when you also need runtime validation — e.g. at API boundaries or before writing to a database. z.infer<typeof schema> keeps both in sync from a single source.

What does the Mongoose output include?

The Mongoose tab generates a Schema definition with inferred types (String, Number, Boolean, Date, Mixed) for each field, a compiled model() call, and optional timestamps: true. Paste it directly into a Node.js / Express project.

Which SQL dialects are supported?

PostgreSQL (uses SERIAL, JSONB, TIMESTAMPTZ), MySQL (INT AUTO_INCREMENT, JSON, DATETIME), and SQLite (INTEGER PRIMARY KEY, TEXT). Toggle the INSERT option to include INSERT INTO statements for the sample values.

What is the OpenAPI output?

The OpenAPI tab produces a components/schemas YAML block compatible with OpenAPI 3.0. Paste it into an existing openapi.yaml to document your API endpoint response shapes with inferred types and required arrays.

How does Mock Data generation work?

The tool inspects the shape and field names of your JSON and generates N synthetic records that match the same structure and types. Names, emails, dates, IDs, and booleans are randomised realistically — useful for seeding databases or testing UIs without real PII.

Is my JSON data private?

Yes — completely. All seven conversion engines run inside your browser using JavaScript. No data is sent to any server. You can even disconnect from the internet and the tool will still work.
