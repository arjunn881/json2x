What is TOML?

            
TOML stands for Tom's Obvious, Minimal Language. It is designed to be easy to read due to obvious semantics and maps unambiguously to a hash table.

          

          

            
Where is TOML used?

            
TOML is the default configuration format in Rust (Cargo.toml), Python packaging (pyproject.toml), Hugo static site generator (hugo.toml), and many Go projects.
