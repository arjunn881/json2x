How to Fix "Unexpected token in JSON"

Understanding the root causes of JavaScript's JSON.parse() unexpected token exception.

The SyntaxError: Unexpected token exception occurs when a JSON parser encounters a character that violates the strict RFC 8259 JSON grammar rules.

Common Causes & Fixes:

  • Single Quotes around Strings or Keys: JSON strictly requires double quotes ("key": "value"). Replace single quotes ' with double quotes ".
  • Unquoted Keys: Object keys like {name: "Alice"} are invalid in JSON. Change to {"name": "Alice"}.
  • HTML returned instead of JSON: If your fetch API returned a 404 or 500 HTML error page, JSON.parse() throws unexpected token <.
