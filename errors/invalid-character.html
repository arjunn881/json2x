Fixing "Invalid Character" Errors

Identify invisible Byte Order Marks (BOM), smart quotes, and unescaped newlines in JSON text.

An Invalid character error is caused when JSON text contains non-standard characters or unescaped control codes.

Common Culprits:

  • Smart / Curly Quotes: Word processors replace straight quotes " with curly quotes “ ”. Replace with straight double quotes.
  • Byte Order Mark (BOM): UTF-8 files saved with a BOM header prefix (\uFEFF) throw parse errors at line 1, column 1.
  • Unescaped Control Characters: Newlines inside strings must be escaped as \n.
