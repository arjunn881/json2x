Fixing Trailing Commas in JSON

Why trailing commas throw parse errors in JSON (unlike JavaScript objects).

While ECMAScript allows trailing commas in JavaScript object literals (e.g. { a: 1, }), standard JSON explicitly forbids trailing commas.

Example of Invalid JSON:

[ "admin", "user", ] ← Trailing comma before closing bracket ]

Correct JSON:

[ "admin", "user" ]
