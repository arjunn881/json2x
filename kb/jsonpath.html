JSONPath Query Syntax

JSONPath enables XPath-like queries on JSON structures to extract specific fields or filter arrays.

Code Example & Usage

// JSONPath Query Examples $.store.book[*].author // Extract all book authors $.store.book[?(@.price < 10)] // Filter books under $10
