Privacy Policy

Last updated: July 28, 2026

TL;DR — The short version

JSON2X processes all data entirely inside your browser. No JSON, CSV, or any other content you paste is ever sent to our servers — because we have no servers.
We do not collect your name, email, IP address, or any personally identifiable information to use the tools.
We display Google AdSense advertisements on some pages. Google's advertising systems may use cookies to show relevant ads. See the advertising section below.
We use no first-party analytics scripts.

1. Who We Are

JSON2X is a free, publicly accessible web service available at json2x.com. It is operated as an independent developer resource with no corporate affiliation.

For any privacy-related queries, you can contact us at: hello@json2x.com

2. Data We Do Not Collect

Because all tool functionality runs as JavaScript code in your browser, the following data is never transmitted to any server:

  • JSON, CSV, or any other content you paste into the tool input fields
  • TypeScript code, JSONPath expressions, or diff results you generate
  • File contents loaded via the file-picker or drag-and-drop
  • Clipboard contents accessed via the "Copy" buttons
  • Any query string or URL fragment parameters you construct

You can independently verify this by opening your browser's Developer Tools (F12), navigating to the Network tab, and confirming that no outbound requests are made when you use any tool. The only network requests made on page load are for the HTML, CSS, and JavaScript assets that constitute the page itself.

3. Data Collected by the Web Server

Like every website on the internet, our static hosting provider automatically records standard web server access logs when your browser requests a page. These logs may include:

  • Your IP address (truncated or anonymised by our hosting provider where applicable)
  • The URL path you requested (e.g., /tools/formatter.html)
  • HTTP referrer header (the page you came from, if any)
  • Browser User-Agent string
  • Timestamp of the request
  • HTTP response status code

These logs are retained for operational and security purposes (e.g., detecting denial-of-service attacks) and are not used for marketing, are not sold to third parties, and are not associated with any personal profile.

4. Cookies

First-party cookies

JSON2X itself does not set any first-party cookies. We do not use cookies for analytics, personalisation, or session management.

Third-party cookies (Google AdSense)

We display advertisements served by Google AdSense. Google's advertising infrastructure may set cookies on your device to serve relevant advertisements based on your browsing history. These are third-party cookies set by Google, not by JSON2X.

You can learn more about how Google uses data when you use our site by visiting Google's Privacy & Terms. You can opt out of personalised advertising by visiting Google Ad Settings or by using the NAI opt-out tool.

At present, JSON2X does not use a cookie consent management platform (CMP). If we introduce cookies that require consent under GDPR or similar regulations, we will update this policy and implement appropriate consent mechanisms.

5. Advertising

JSON2X is free to use and is supported by display advertising served through Google AdSense. Ad slots appear in clearly delineated zones on our pages — below the hero section and below the tool output area. We do not place ads that:

  • Overlay or obscure tool functionality
  • Appear above the primary site navigation
  • Mimic or are adjacent to interactive tool buttons
  • Auto-play audio or video
  • Expand on hover without user interaction

All advertising placements are reviewed for compliance with Google AdSense Program Policies before publication.

JSON2X is a developer tool intended for general audiences. We do not knowingly collect any personal information from children under the age of 13. If you believe a child has submitted personal information to us, please contact us at hello@json2x.com so we can take appropriate action.
