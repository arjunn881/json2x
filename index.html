JSON2X — Tool Guide

Every tool on this site is free, requires no sign-up, and runs 100% inside your browser. Here's a quick guide to which tool fits which task.

Format JSON online — prettify and validate in one step
Paste minified or hand-edited JSON to indent it, apply syntax highlighting, and instantly know whether the document is valid. Supports 2-space, 4-space, and tab indentation.
Validate JSON syntax with exact line-level error messages
When you need to know exactly what's wrong — and where — before making an API call or committing a config file. Reports the precise line and column of every syntax error.
Minify JSON to reduce payload size before sending to an API
Strip all whitespace and see the exact byte savings before and after — useful for optimising REST API payloads, localStorage usage, or embedded configuration strings.
Compare two JSON objects and highlight structural differences
Deep structural diff — not a line diff. Spots added keys in green, removed in red, and changed values in amber, regardless of key order within objects.
Convert a JSON array to a downloadable CSV spreadsheet
Ideal for exporting API data to Excel or Google Sheets. Flattens nested objects using dot notation and produces a properly quoted CSV file ready to download.
Parse a CSV file into structured JSON with type inference
Auto-detects comma, semicolon, and tab delimiters. Handles quoted fields containing commas, infers numeric and boolean types, and outputs formatted JSON.
Generate TypeScript interfaces from JSON — with Zod schema output
Paste any API response to get typed interface declarations. Nested objects become named sub-interfaces. Switch tabs to get the matching Zod runtime validation schema.
Test JSONPath expressions and see matches update live
Write and refine $..author, [?(@.price < 10)], or any other JSONPath query against real data. Includes an operator reference table and 7 clickable presets.
Generate a JSON Schema draft-07 document from any sample JSON
Automatically infers types, required fields, and nested structure. Outputs a valid $schema document compatible with Ajv, Postman, and OpenAPI validators.
Explore large JSON responses as a collapsible, searchable tree
When formatted text is too hard to read — collapse branches, search keys and values, and see type labels and node counts at every level without scrolling through thousands of lines.
